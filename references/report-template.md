## Quality bar

- Every code finding has **file + fix + impact + effort**, mapped to a checklist item.
- Submission steps are **explicit** (where + how + link).
- Before/after uses **real GSC data**, not estimates; caveats stated.
- No claim that `llms.txt` alone "ranks you in AI" — the honest levers are crawlability, structured data,
  clear content, and citations.
